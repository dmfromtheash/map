# CLAUDE.md — вход для Claude Code

@AGENTS.md

Общие обязательные правила Map находятся в `AGENTS.md`. Этот файл только связывает их с Claude
Code и не дублирует проектную политику.

Перед работой прочитать `CODEX.md`, `docs/STATE_HANDOFF.md` и относящиеся к задаче решения.
Использовать только инструменты, которые реально доступны в текущей сессии. Не считать доступными
Codex apps/plugins, `.agents/skills` или другие provider-specific возможности. Project skills из
`.claude/skills/` подключать по смыслу задачи. Они дополняют, а не заменяют решение владельца
и `AGENTS.md`. Подагентов автоматически не запускать.

Короткий шаблон задачи для Claude находится в `docs/ai/PROMPT_CLAUDE.md`.

## Работа над Map

- Прочитай `docs/ai/CLAUDE_WORKFLOW.md` при первом запуске или смене модели. Профиль выбирается
  по фактически выбранной модели; имя в тексте промпта само модель не переключает.
- Для реализации функции используй `map-local-feature`; для контуров и связанных объектов —
  `map-linked-geometry`; для сравнения холста с образцами — `map-visual-compare`.
- Для подготовки следующего поручения по названию модели — `map-claude-prompt`.
- Контекст текущей копии показывает `tools/ai/Get-MapContext.ps1`. Он ничего не меняет.
- В `.mcp.json` настроен Microsoft Learn для справки по .NET. Сначала проверь наличие его
  инструментов в сессии. Сеть нужна справочнику, основные функции Map остаются офлайн.
- Источники и кандидаты для Stages 19–24: `docs/ai/RESEARCH_AND_REPOSITORIES.md`.
  Это подборка для выбора, не установленный набор зависимостей и не разрешение начать этапы.
