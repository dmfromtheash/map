Map — конструктор карт (Windows 10/11, 64-bit)

КАК УСТАНОВИТЬ
1. Распакуйте архив целиком: правой кнопкой по архиву → «Извлечь всё…». Из архива напрямую не запускать.
2. В распакованной папке Map дважды щёлкните «Установить Map.exe» → «Установить».
   Программа скопируется в вашу папку пользователя (права администратора не нужны), появятся ярлыки
   «Map — конструктор карт» на рабочем столе и в меню «Пуск», и Map откроется.
3. Дальше запускайте Map ярлыком. Распакованную папку после установки можно удалить.
4. Устанавливать .NET не нужно: всё нужное уже внутри.

БЕЗ УСТАНОВКИ
Можно просто запустить Map.App.exe из распакованной папки — программа работает и так.

ЕСЛИ WINDOWS ПРЕДУПРЕЖДАЕТ
Сборка не подписана, поэтому SmartScreen может показать «Windows защитила ваш компьютер».
Нажмите «Подробнее» → «Выполнить в любом случае». Это нужно один раз.

ГДЕ КАРТЫ
Карты хранятся в папке «Документы\Map» (файлы .mapproj), там же экспорт в PNG/JPEG/WebP.

ОБНОВЛЕНИЕ
Скачайте новый архив с https://github.com/dmfromtheash/map/releases, распакуйте и снова запустите
«Установить Map.exe» — старая версия заменится. Карты и библиотека при этом не трогаются.

УДАЛЕНИЕ
Параметры Windows → «Приложения» → «Map — конструктор карт» → «Удалить».
Карты в «Документы\Map» остаются.

Исходный код: https://github.com/dmfromtheash/map
