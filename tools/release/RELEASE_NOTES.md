Готовая сборка Map для Windows 10/11 x64.

**Как запустить**

1. Скачайте `Map-<версия>-win-x64.zip` ниже.
2. Распакуйте архив целиком в любую папку (например, `C:\Map`).
3. Запустите `Создать ярлык на рабочем столе.cmd` — появится ярлык «Map — конструктор карт», и программа откроется.

Устанавливать .NET не нужно: среда выполнения внутри архива. Сборка не подписана: если SmartScreen предупреждает, нажмите «Подробнее» → «Выполнить в любом случае». Карты сохраняются в `Документы\Map`. Подробности — в `ЧИТАЙ-МЕНЯ.txt` внутри архива.
