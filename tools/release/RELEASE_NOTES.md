Готовая сборка Map для Windows 10/11 x64.

**Как установить**

1. Скачайте `Map-<версия>-win-x64.zip` ниже.
2. Распакуйте архив целиком: правой кнопкой → «Извлечь всё…».
3. В распакованной папке `Map` запустите **`Установить Map.exe`** → «Установить». Появятся ярлыки «Map — конструктор карт» на рабочем столе и в «Пуске», и программа откроется. Права администратора не нужны.

Без установки тоже можно: запустите `Map.App.exe` из распакованной папки.

Устанавливать .NET не нужно: среда выполнения внутри архива. Сборка не подписана: если SmartScreen предупреждает, нажмите «Подробнее» → «Выполнить в любом случае». Карты сохраняются в `Документы\Map`. Удалить — «Параметры» → «Приложения» → «Map — конструктор карт». Подробности — в `ЧИТАЙ-МЕНЯ.txt` внутри архива. Что нового — в [CHANGELOG.md](https://github.com/dmfromtheash/map/blob/main/CHANGELOG.md).
