# Map.Performance

Локальный deterministic runner Stage 13. Проект намеренно не входит в `Map.slnx` и не запускается
обычной сборкой приложения. Generated JSON записывается в ignored `tmp/performance` либо в явно
переданный `--output`.

```powershell
dotnet run --project .\tools\Map.Performance\Map.Performance.csproj -c Release -- `
  --profile stage13a --object-count 50000 --seed 13013 --warmup 1 --iterations 5
```

Доступные профили текущего среза: `stage13a`, `stage13b-baseline`, `stage13b`,
`stage13c-baseline`, `stage13c`, `stage13d`, `small-render`, `hit-test`, `marquee`,
`object-tree`, `spatial-query` и соответствующие `native-stage13a`…`native-stage13d`.
Перед/после сравниваются с одинаковыми `seed`, `object-count` и fixture hash. CPU-render timing
не выдаётся за native input-to-present: native-профиль открывает отдельное настоящее off-screen
окно без активации и системного ввода, считает реализованные строки и измеряет путь от
interaction-start до завершения Skia scene pass. `stage13d` дополнительно проверяет 131K sparse
canvas, bounded export plan, 50K/100K save-reopen и test-only 262K boundary; 262K не меняет
production policy.

## Адресная проверка Stage 18

`--profile native-stage18 --output <внешняя-папка>/native.json` проверяет создание вогнутой
области, локальную границу/плотность, отделение, Undo/Redo, сохранение, reopen с пустым
каталогом, текущую карточку, bake/delete и PNG. `MAP_STAGE18_FIXTURE` указывает существующий
`.mapproj` порядка 20 тысяч объектов: измеритель создаёт временную копию и проверяет SHA
оригинала. Собственное окно `ShowActivated=false`, без системного ввода; все изменяемые пути
изолированы. Report разделяет scoped events, adapter calls, время до кадра, private bytes,
allocated UI bytes, retained heap с историей/индексами/кадром и число затронутых/разделённых ячеек.
Это отдельный адресный прогон по запросу, не часть обычного build или полного suite.
После изменения только панели можно указать `MAP_STAGE18_UI_ONLY=1` и `MAP_STAGE18_UI_FIXTURE`
с уже проверенным проектом области: отдельный короткий сценарий проверяет подпись плотности,
изменение параметров, карточку сохранённого ассета, отмену/повторный выбор и сохранение либо
корректный отказ по реальному допуску памяти. Report явно называет исход сохранения; полный
сценарий и успешный замер большой карты не повторяются. Для каждого запуска нужна новая внешняя
папка результатов; fixture не перезаписывается.

Расстановка Stage 18 учитывает размеры изображений. Полный профиль проверяет нулевое число
пересекающихся пар штампов, а UI-профиль на раннем проекте области также нажимает «Разместить
без наложений» и проверяет сохранность оставшихся экземпляров и точный Undo/Redo. Для замера
на заполненной карте создаётся отдельный пустой объектный слой только в её временной копии:
исходные 20 тысяч объектов сохраняются. Непустая локальная правка границы выбирается по геометрии
до запуска таймера, без пробных правок; её конечная X-координата записывается в report.
