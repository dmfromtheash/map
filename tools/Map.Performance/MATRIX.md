# Живая матрица функций и стилей

Профиль `native-million-assets` открывает настоящее окно редактора и холст.
Дополнительные маршруты включаются только переменными окружения:

```powershell
$env:MAP_DRIVE_LIBRARY_ROOTS='D:\MapLibrary'
$env:MAP_MEASURE_GPU_FLUSH='1'
$env:MAP_MILLION_CASE='giant' # standard, giant, hex, light, style
$env:MAP_MILLION_STYLE='WatercolorBigShapes' # off или точное имя MapStylePreset
$env:MAP_MILLION_FUNCTIONS='navigation,terrain,water-road,placement,layout,selection,style-light,export'
$env:MAP_MILLION_STEPS='600'
$env:MAP_MILLION_CACHE='warm' # reset-render: сброс только кэшей отрисовки
dotnet run --project tools/Map.Performance -c Release --no-build -- --profile native-million-assets --object-count 1000000 --output C:\Checks\matrix.json
```

`hex` требует `MAP_MILLION_CASE=hex`; `all` включает его тоже. Количество шагов120–6000,
по умолчанию600. Короткий120-шаговый запуск проверяет инструмент, не заменяет приёмку
миллиона. Без переменных функций/стиля остаётся прежний маршрут native-million-assets.

Сцена матрицы содержит исходное количество штампов, сушу на62%ширины с пропуском
каждой17-й плитки, реку и дорогу. Одинаковые байты покрытия земли разделяются между
плитками: это проверка большой площади, а не16ГиБ уникальных нарисованных данных.

Маршруты: панорама/колесо, кисти земли/материала/скал/рельефа/маски, река/озеро/дорога,
расстановка/серия, раскладка пути/области, выделение/перенос/поворот/размер/текст,
стиль/свет, гексы, предпросмотр экспорта. Изменения проверяются через Undo/Redo и
сравнение затронутого состояния документа. Ввод идёт через штатный canvas/router и
публичные команды редактора; это не проверка аппаратного ввода мыши/мониторного scan-out.

Отчёт различает время работы кадра, интервалы кадров и ввод→кадр; сохраняет1%low,
p95/p99/max, число пауз, подготовку после жеста и кадры setup/reset. Счётчик всех кадров
охватывает также уточнение и экспортный preview. Снимки окна и GPU сохраняются вместе;
их нужно просмотреть и сравнить окончательные пиксели. Функциональное прохождение
маршрута не означает прохождение порогов FPS. Все стили enum и ручные сценарии
(массовое выделение, реальные диалоги/горячие клавиши) требуют отдельных строк приёмки.
