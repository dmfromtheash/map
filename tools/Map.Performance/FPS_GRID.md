# Сетка размеров и количества объектов

`native-million-assets`: `MAP_MILLION_SIDE=8192|32768|131072|262144` задаёт квадрат.
Допустимы1024..262144; свыше131072 — диагностическая сцена вне продуктового лимита
создания карты, сам лимит не меняется. `--object-count` допускает до2000000.
Без переменной размеры и маршруты прежние. Объекты равномерно распределены по всей
странице (seed13013), SHA библиотеки равномерно чередуются, последний штамп по центру.

`MAP_PERF_FPS_GRID=1` включает300шагов на жест: pan fit/100/400/1600%, колесо
fit→100→400→1600→400→100→fit, pan от края до края при100%;10выборов/переносов,
10штампов, Undo/Redo. Колесо — дробныйdelta через штатный обработчик, выбор/перенос —
публичные команды редактора (прозрачный центр ассета не ломает тест попадания).
Реальное окно и GPU canvas; аппаратный ввод/scan-out не измеряются.

Сетка требует оригинальную библиотеку, без portable fixture, стиля и функций матрицы.
Машинный кэш заготовок общий тёплый; GPU/render cache новый на процесс. Прогрев
определяется отдельно от времени открытия. Исходники библиотеки только читаются.

Для серии на пополняемой библиотеке задавать `MAP_PERF_CATALOGS` (имена прямых
каталогов через `;`) и `MAP_PERF_ASSET_SHA_FILE` (один уникальный SHA-256 на строку).
Перед созданием сцены инструмент проверяет полное равенство списка содержимому
подключённых каталогов; новое/удалённое изображение прерывает запуск, а не меняет
раскладку незаметно. Отчёт сохраняет имена каталогов и SHA-256 отсортированного
списка SHA, соединённого LF без завершающего LF. Без переменных читаются все каталоги.

`medianWindowFps` — медиана числа завершённых кадров в равных окнах≈1с за весь
интервал от первого ввода до последнего кадра; пустые окна не исключаются. `fps` —
общая пропускная способность.1%low — обратное среднему худших1%интервалов кадров.
Время работы кадра, ввода и settled записываются отдельно. Цветячейки — худшая
медиана жеста: ≥60зелёный,20..60жёлтый,<20красный; функция/жест указаны рядом.
Неполный запуск не является полной ячейкой; сохраняется `.progress.json`.

Запускать последовательно, удалять временныйпрофиль, просматривать снимки.
При median pan<10 останавливать рост количества в этой строке; непроверенные
ячейки обозначатьNOT CHECKED, а не выдавать предполагаемое ухудшение за замер.
