# Map

Map — личный нативный офлайн-конструктор карт для текущего Windows x64 ПК владельца. Это не сайт
и не облачный сервис.

## Запуск

Требуется установленный .NET 10, который уже есть на рабочем ПК.

```powershell
dotnet run --project .\src\Map.App\Map.App.csproj -c Release
```

Или сначала собрать production-код:

```powershell
dotnet build .\Map.slnx -c Release
.\src\Map.App\bin\Release\net10.0\win-x64\Map.App.exe
```

`Map.slnx` содержит только приложение и его production-библиотеки. Тестовые проекты сохранены
отдельно и не запускаются обычной сборкой. При исправлении конкретной логики запускается только
относящийся к ней test-project/фильтр.

## Размер папки

Исходники Map занимают считанные мегабайты. `bin/`, `obj/` и `artifacts/` — воспроизводимые
результаты сборок и проверок, они не являются приложением и игнорируются Git. Нативные symbol-файлы
Skia/HarfBuzz автоматически удаляются из локального output, а сборка ограничена `win-x64`.

## Текущая точка развития

Реализации Stages 12A–16 сохранены в линейной продуктовой истории. Нового номерного этапа сейчас
нет. Функциональная проверка не означает полной готовности: остаются ограничения каталога,
миниатюр и неподтверждённая производительность подробного масштаба. Точный
рабочий каталог, ветка, `HEAD` и состояние незакоммиченных файлов указаны в
`docs/STATE_HANDOFF.md`; старый checkout Stage 10D не является продуктовой базой.
