# Map

[![build](https://github.com/dmfromtheash/map/actions/workflows/build.yml/badge.svg)](https://github.com/dmfromtheash/map/actions/workflows/build.yml)

Map — нативный офлайн-конструктор карт для Windows 10/11 x64: стандартный конструктор (земля,
реки, дороги, области, штампы, заметки, экспорт PNG/JPEG/WebP) и гексовый конструктор (поле
гексов, регионы, пути, туман войны, ключ гексов, подкарты, экспорт JSON и для Foundry/Roll20).
Это не сайт и не облачный сервис: всё работает без интернета.

## Скачать и запустить

1. Скачайте архив `Map-<версия>-win-x64.zip` со страницы
   [последнего релиза](https://github.com/dmfromtheash/map/releases/latest).
2. Распакуйте его целиком в любую папку (например, `C:\Map`).
3. Запустите `Создать ярлык на рабочем столе.cmd` — появится ярлык «Map — конструктор карт»
   и программа откроется. Дальше запускайте Map этим ярлыком или файлом `Map.App.exe`.

Устанавливать .NET не нужно: среда выполнения включена в архив. Сборка не подписана, поэтому
SmartScreen при первом запуске может показать предупреждение: «Подробнее» → «Выполнить в любом
случае». Карты сохраняются в `Документы\Map` как файлы `.mapproj`. Подробнее — `ЧИТАЙ-МЕНЯ.txt`
в архиве.

Новый релиз собирается скриптом `tools/release/publish-release.ps1` (самодостаточная сборка
win-x64 с ReadyToRun, помощник ярлыка и инструкция в одном zip).

## Запуск из исходников

Требуется установленный .NET 10, который уже есть на рабочем ПК.

```powershell
dotnet run --project .\src\Map.App\Map.App.csproj -c Release
```

Или сначала собрать production-код:

```powershell
dotnet build .\Map.slnx -c Release
.\src\Map.App\bin\Release\net10.0\win-x64\Map.App.exe
```

`Map.slnx` содержит только приложение и его production-библиотеки. Тестовые проекты сохранены
отдельно и не запускаются обычной сборкой. При исправлении конкретной логики запускается только
относящийся к ней test-project/фильтр.

## Размер папки

`bin/`, `obj/` и `artifacts/` — результаты сборок и проверок, они игнорируются Git;
локальная сборка приложения запускается из `bin/`. Графика интерфейса остаётся в проекте. Нативные symbol-файлы
Skia/HarfBuzz автоматически удаляются из локального output, а сборка ограничена `win-x64`.
