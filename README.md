# Map

Map — личный нативный офлайн-конструктор карт для текущего Windows x64 ПК владельца. Это не сайт
и не облачный сервис.

## Запуск

После очистки библиотеки (DEC-040) владелец оставил единственное покрытие земли
«Акварель · подножие гор» (DEC-042). Добавленная гора затем удалена по его запросу (DEC-043).
Новые слои земли используют это покрытие. В инструменте «Земля → Раскрасить» доступны
материал, цвет и ластик. Активная библиотека объектов сейчас пуста.

Требуется установленный .NET 10, который уже есть на рабочем ПК.

```powershell
dotnet run --project .\src\Map.App\Map.App.csproj -c Release
```

Или сначала собрать production-код:

```powershell
dotnet build .\Map.slnx -c Release
.\src\Map.App\bin\Release\net10.0\win-x64\Map.App.exe
```

`Map.slnx` содержит только приложение и его production-библиотеки. Тестовые проекты сохранены
отдельно и не запускаются обычной сборкой. При исправлении конкретной логики запускается только
относящийся к ней test-project/фильтр.

## Размер папки

`bin/`, `obj/` и `artifacts/` — результаты сборок и проверок, они игнорируются Git;
локальная сборка приложения запускается из `bin/`. Графика интерфейса остаётся в проекте. Нативные symbol-файлы
Skia/HarfBuzz автоматически удаляются из локального output, а сборка ограничена `win-x64`.

## Текущая точка развития

Реализации Stages 12A–19 сохранены в продуктовой истории. Stage 20 (дороги) находится в рабочей
копии и остаётся **PARTIAL**. Пять технических дефектов проверки 08.09 исправлены по DEC-034;
художественная доводка и полная приёмка остаются открыты.
Stages 21/22 отложены владельцем. Художественное наполнение Stages 23/24 удалено для переделки:
в библиотеке 0 ассетов и 0 доступных материалов, исходные горные/текстурные пакеты удалены.
Кисть Земли, мягкие переходы, ластик раскраски, импорт и каталог сохранены; доступно рисование цветом.
Автоматическое добавление старых наборов отключено.
Порядок создания нового наполнения описан в `docs/09_ASSET_PIPELINE_AND_LICENSING.md`.
Точный рабочий каталог, ветка, `HEAD`, открытые проблемы и следующее действие указаны в
[STATE_HANDOFF](docs/STATE_HANDOFF.md). Старый checkout Stage 10D не является продуктовой базой.
