# V0 · свой конвейер света на SkiaSharp (прототип, выбран владельцем 2026-10-24)

Прототип сравнения «движок против своего» (DEC-056 → DEC-057). Не входит в `Map.slnx` и в CI;
пакеты те же, что у Map (Avalonia 12.1.1, SkiaSharp 3.119.4). Основа для внедрения света в R09.

## Что внутри

| Файл | Роль |
|---|---|
| `SceneInputs.cs` | читает `scene/scene.json` и слои; спрайты гор: цвет, нормали, данные (маска силы света, высота) |
| `MaterialCache.cs` | тайлы 512² цвета, нормалей и данных — строятся один раз; сборка видимого кадра из тайлов |
| `LightPass.cs` | один SkSL-проход: солнце по нормалям (смешано с рисунком по маске), подсветка, огни с ореолами, вода, туман внизу, баланс белого, экспозиция, насыщенность; ключи времени суток |
| `ShadowLayer.cs` | тени гор от основания: силуэт кладётся перед подножием, наклон от солнца, полутень растёт с длиной, контактная тень |
| `Program.cs` | окно на втором дисплее, GPU-контекст Avalonia (как в `MapCanvasControl`), режимы `stills`, `video`, `perf`, `export` |
| `tools/*.py` | генераторы общей сцены: карты формы гор (`shape_maps.py`), равнина/обрыв/вода и сценарий света (`scene.py`), листы проверки |

Входные данные (копии гор владельца и производные карты) в репозиторий **не** кладутся: собираются
скриптами `tools/` в отдельной папке из `%LOCALAPPDATA%\Map\Assets\originals` (копия, профиль не трогать).

## Запуск

```powershell
py -3 tools/shape_maps.py <shared> 1024   # нужна папка <shared>/art с glacier.png, twin.png, peak.png
py -3 tools/scene.py <shared>
dotnet build -c Release -m:1 -nr:false -p:UseSharedCompilation=false
bin\Release\net10.0\win-x64\V0Skia.exe --shared <shared> --out out --mode stills|video|perf|export|all
```

## Итоги замеров (2026-10-24, RTX 3070 Laptop, OpenGL/ANGLE, 2560×1440)

- Смена света: 0 перестроенных тайлов из 15; полное время кадра (запись + GPU + ожидание) медиана 3,4 мс, p95 6,9 мс —
  порог «≤ 4 мс GPU p95» не подтверждён (таймера GPU в Skia нет).
- Экран = экспорт на одинаковых входах: ≤ 1 уровень RGB; тайловый экспорт 2×2 с полем 400 px против цельного: ≤ 1.
- Материал, собранный отдельно на GPU и на CPU (mip-уровни): до 8 уровней в 61–245 точках у подножий.

## Известное (владелец 2026-10-24)

- Тени «будто иногда оторваны от объекта» — доработать посадку тени к подножию (контакт, форма следа).
- Карты формы гор черновые; выбор «бережный / выраженный рельеф» — отдельно.
- Огни считаются по всему кадру — при внедрении отбирать по области.
