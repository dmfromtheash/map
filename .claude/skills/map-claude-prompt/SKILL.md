# Промпт для выбранной модели

Прочитай `docs/ai/CLAUDE_WORKFLOW.md` и `docs/STATE.md`.
Источником model ID и особенностей профиля служит `docs/ai/claude-models.json`.
Если версия модели изменилась, проверь официальные Anthropic docs до обновления профиля.
Название модели и доступные инструменты среды — разные вещи.

Не подставляй старый номер этапа из примера. Отложенные этапы (R36/R37 и помеченные ⏳/⏭ в
`docs/ROADMAP_2026-10_PROGRESS.md`) не разрешают поручение без нового решения владельца.

Из корня Map:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/ai/New-ClaudeTask.ps1 -Model Fable
powershell -NoProfile -ExecutionPolicy Bypass -File tools/ai/New-ClaudeTask.ps1 -Model Opus -Stage R09
```

Без `-Stage` берётся «Следующий шаг» из `docs/STATE.md`; сама команда этап не выполняет.
Для конкретного исправления передай `-Task 'наблюдаемый результат'`. Готовый промпт сохраняй
одним файлом в `docs/ai/`, прежний промпт сессии переноси в `docs/archive/prompts/`.

Прочитай получившийся текст перед передачей: цель соответствует последнему сообщению, исходная
папка и Git взяты из live context, незавершённая текущая работа не потеряна, будущий этап не
начат молча, инструменты действительно существуют. Явное разрешение на commit и прочие
действия переноси только из поручения владельца, не из чужой исторической задачи.

Верни владельцу готовый промпт. Для Opus — ясный срез и инварианты; для Fable — цель целиком,
границы и критерии результата со свободой выбрать способ. Это проектные рекомендации,
не гарантия превосходства одной модели и не вымышленные свойства её поведения.
