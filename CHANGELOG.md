# Changelog

Заметные изменения Map фиксируются здесь. Проект использует Semantic Versioning для версии
приложения; версии схем `.mapproj` и локального каталога ведутся отдельно.

## Текущая разработка

### Changed

- Репозиторий и инструкции упрощены под единственный целевой компьютер владельца: Windows x64.
- Из основной структуры удалены старые этапные промты, отчёты, драйверы и бенчмарки.
- Реализации Stages 12A–16 сохранены в линейной продуктовой истории; нового номерного этапа нет.
- Аудит 2026-09-05 подтвердил основные локальные сценарии и сохранил открытые ограничения
  каталога, миниатюр, защитных бюджетов и производительности; подробности в `docs/STATE_HANDOFF.md`.
- Рабочие правила Codex и Claude сведены к одному источнику без статических каталогов tools.
- Stage 19: допуск памяти учитывает реальную стоимость операции, поэтому небольшая правка,
  сохранение и экспорт небольшой карты не требуют закрывать другие приложения; реки и озёра
  участвуют в обычном выборе, перемещении, удалении, списке объектов, скрытии, блокировке и
  переносе между слоями; форма русла управляется кривизной узла, сглаживание не добавляет узлов,
  извилины показываются до применения; попадание считается по видимому телу; вырезанное рекой
  покрытие земли переиспользуется без изменения картинки.
