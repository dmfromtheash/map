# Changelog

Заметные изменения Map фиксируются здесь. Проект использует Semantic Versioning для версии
приложения; версии схем `.mapproj` и локального каталога ведутся отдельно.

## Unreleased

### Added

- Единый источник development-версии приложения и проверка её согласованности.
- Версия собранного приложения видна в заголовке настоящего Windows-окна.
- Основа неизменяемых локальных `win-x64` bundle для проверки обновления и ручного отката.

### Changed

- Проверочные prompt'ы получили конечный verification budget и явные stop rules.

## 0.2.0 — development baseline

Это внутренняя точка версии уже существующего приложения, а не опубликованный релиз. История
реализации Stages 1–10D остаётся в `docs/STATE_HANDOFF.md` и `docs/reviews/`.
