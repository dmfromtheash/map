# Changelog

Заметные изменения Map фиксируются здесь. Проект использует Semantic Versioning для версии
приложения; версии схем `.mapproj` и локального каталога ведутся отдельно.

## Unreleased

### Changed

- Репозиторий и инструкции упрощены под единственный целевой компьютер владельца: Windows x64.
- Из основной структуры удалены старые этапные промты, отчёты, драйверы, бенчмарки и release-обвязка.
- Следующий продуктовый этап — Stage 12A: именованные контрольные точки карты.

## 0.2.0 — development baseline

Это внутренняя версия уже существующего приложения, а не опубликованный релиз. Текущее состояние
и следующая задача описаны в `docs/STATE_HANDOFF.md`.
