## 5. Замеченные ловушки (сессия 3)
- `dotnet build Map.slnx` не пересобирает тестовые проекты — счётчики тестов не растут; собирай `tests/<проект>` явно.
- На ПК владельца ~2 ГБ свободной ОЗУ: экспортные тесты параллельно ложно падают «Недостаточно свободной памяти…»;
  `WorkingMemoryBudgetTests` падают, пока другой процесс (выгрузка, просмотр PNG) держит замок тяжёлых операций.
- Пока работает Map.App из папки сборки (например, просмотр PNG), `src/Map.App/bin` заблокирован — инструменты
  собирать с `-p:OutDir=<временная папка>`; не запускать Map.App владельцу из рабочей папки сборки.
- В bash-heredoc с кириллицей и `\U` в путях Python падает — писать скрипты правок через Write в scratchpad.
- Кнопки-переключатели (`AppearanceToggle`) реагируют на `Click`, не на `IsChecked` — в смоуках поднимать `ClickEvent`.
- `PlacementArea` сериализуется как запись Core: новые поля — только с `JsonIgnore(WhenWritingDefault/Null)`, иначе
  старые области «потянут» новую схему.
