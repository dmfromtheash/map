# Шаблон задачи для Codex (GPT-6.1 Sol / GPT-6 Astra)

> **Не использовать: Codex отключён владельцем 2026-10-30 (DEC-075, `AGENTS.md`).**

Задачу Codex ставит Claude после «да» владельца (`AGENTS.md §Второй исполнитель`). Промпт
подаётся файлом: `codex exec -m <модель> -c model_reasoning_effort=<high|xhigh> -C <папка> -o <отчёт> - < prompt.md`.
Песочница `-s read-only` в конфигурации владельца не действует — запрет правок писать в тексте.

```text
Рабочая папка: [продуктовая папка или worktree codex/roadmap-<этап>]
Вид работы: [реализация / исправление / аудит (ТОЛЬКО ЧТЕНИЕ, файлы не менять) / исследование]

Цель
[Один наблюдаемый результат.]

Контекст
- Прочитай docs/STATE.md, AGENTS.md, CODEX.md, чек-лист docs/00_STAGE_PROTOCOL.md.
- [Нужные файлы, спецификация, запись журнала.]

Карточка этапа
- Входит: [закрытый список.]   Не входит: визуал, соседние этапы, [прочее].
- Файлы: [что разрешено менять.]
- Готово, когда: [проверяемые условия и проверки с командами.]

Ограничения ПК
- Одна тяжёлая операция за раз; сборка с -m:1 -nr:false -p:UseSharedCompilation=false.
- Map владельца не трогать; тестовые запуски — в изолированном профиле; за собой всё удалить.
- Правки apply_patch, BOM/CRLF как в HEAD.

Финал
- [Коммитить или нет — явно. Push делает Claude после проверки.]
- Отчёт: что изменено (файлы), что проверено (N/N), что не проверено; раздел ИТОГИ по AGENTS.md.
```
