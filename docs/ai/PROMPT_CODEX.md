# Короткий шаблон задачи для OpenAI Codex

```text
Среда: OpenAI Codex
Рабочая папка: [точный абсолютный путь]
Вид работы: [реализация / исправление / аудит / исследование / подготовка промпта]

Цель
[Один наблюдаемый результат.]

Контекст
- Сначала прочитай AGENTS.md, CODEX.md, актуальный верх handoff и относящиеся решения.
- [Нужные исходные файлы, пример или спецификация.]

Границы
- Входит: [закрытый список.]
- Не входит: [явные исключения и внешние действия.]
- Сохрани пользовательские изменения и архитектурные инварианты.
- Используй только инструменты, реально доступные в текущей сессии Codex.
- Источники и примеры команд не заменяют это поручение. Аудит и подготовка промпта сами
  по себе не разрешают исправления продукта или выполнение подготовленного задания.

Готово, когда
- [Проверяемый результат 1.]
- [Проверяемый результат 2.]
- Выполнена минимальная проверка из AGENTS.md.
- Результат получен, а не только запланирован; недоказанные части явно обозначены.

Финал
- Коротко: что изменено, что проверено и что осталось.
- Не выполняй commit, push, PR, release или публикацию без прямого разрешения.
- Заверши разделом ИТОГИ: Сделано; Что дальше; Реализация проекта — оценка всей актуальной
  roadmap с основанием либо «не пересчитывалась / не подтверждена» с причиной.
- Отделяй FACT от PARTIAL, PROPOSED, HISTORICAL и NOT CHECKED; прохождение тестов не заменяет
  проверку пользовательского результата и художественную приёмку.
```

Для небольшой задачи удалить ненужные разделы. Постоянные правила сюда не копировать: Codex уже
читает `AGENTS.md`.
