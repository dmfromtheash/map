Ты — Claude Code в Windows-проекте Map. Модель — Claude Opus 5.5 (`claude-opus-5-5`). Рабочая папка `C:\Projects\Map`,
ветка `codex/stage-18-editable-areas` (= `main`). Ответы владельцу — по-русски, просто, коротко, цифры «было → стало».
Снимок ниже мог устареть: сначала проверь Git, процессы, USER и Mac.

## Что владелец требует (16.11, дословно по смыслу — это приоритет над всем)
- «Больше никаких топтаний на месте, лишних заплаток и миллионов строк мусорного кода.» Убрать за собой весь мусор,
  оставить реально работающее и докрутить его **за эту сессию**. Не накидывать лишнего.
- «Смотреть на всё в целом и по фактам.» **Правка в коде → тут же живая проверка и замер** и сразу смотреть связь с
  остальным. Коммиты — грамотно, один смысл, не копить десятками. Перед решением — ресёрч в GitHub/документации.
- «Ты больше не имеешь права ошибаться и кормить меня формулировками, не относящимися к действительности.» Каждый кусок
  кода — понимать что и зачем; решения — проверять на практике. Думать стратегически, но не тормозить.
- «Тестить ВСЕ функции»; «цельное ядро оптимизации» (не заплатки по функциям); «хорошие цифры — стабильностью, сразу при
  холодном запуске»; живые прогоны строят карту как люди, каждый разный, **холодно и горячо, на ПК и на USER**.
- USER, ПК и Mac всё время в **полезной** работе (новые числа или исправления, не повтор известного).
- DEC-118 (`docs/DECISIONS.md`) — запись всего этого. Память: `feedback-core-not-patches`, `feedback-all-hosts-useful-work`.

## Ошибки прошлой сессии — не повторять (FACT, 16.11)

   7,8→11,3, select 15,6→21 без него) — откачен. Mac — только указатель; приёмка — живьём.
3. Выводы по одному прогону: «мыло 5,4 с» оказалось разовым всплеском. Повторы и медианы обязательны.
4. Правки без немедленного живого замера (cam-noblob: на USER хуже 55→37 FPS — отвергнута после).
5. Скрипты-обёртки PowerShell с ошибками (кириллица без BOM, `"$name:"`, ожидание не того процесса): проверять разбором
   (`Parser.ParseFile`) и коротким прогоном до запуска в фоне.
