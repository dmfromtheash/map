- Весь вид панели и карточки делает только Claude. DEC-070 уже выбрал раскладку («вариант 1 + поиск из варианта 5»,
  макет https://claude.ai/artifact/5JTvygDvWMazmUQw2q1d12). Если по ходу нужен новый визуальный выбор (вид групп в
  панели, вид карточки) — сначала живой макет на весь экран с вариантами, внедрять после выбора владельца.
- Ничего не теряется: каждая функция полос доступна из панели или раздела, Undo/Redo и привязки команд те же;
  документ — источник истины, рендер не меняет документ.
- Окна Map и тестов — только на втором дисплее (ноутбук), во весь экран; экран владельца не брать. Если второго
  дисплея нет — живые проверки отметить NOT CHECKED, не открывать окна на основном.
- Без `--ui-tour` и обхода всего интерфейса. Временные файлы и выгрузки удалять сразу после проверки.
