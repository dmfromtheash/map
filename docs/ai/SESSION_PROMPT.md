- Core не зависит от UI/Skia; документ — источник истины; рендер не меняет документ; всё отменяется; сохранение
  атомарное. Схема: менять только если нужно (свободна v54) — с тестом чтения/записи.

  Страницы результата — открывать в его браузере (`Start-Process`, браузер Brave) и проверять, что окно не свёрнуто.
- Sol/Astra — только если владелец скажет «да» на конкретную задачу (DEC-089), с явной песочницей.
- Своё временное (выводы смоуков, временные папки) удалять сразу; копии/бэкапы — только по вопросу с размером.
- Проверки по AGENTS.md: Release-сборка `Map.slnx`; тесты затронутых проектов по фильтру; один смоук профиля и
