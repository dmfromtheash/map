## Цель

Довести этап «автогенерация по референсам» до конца: генерация ставит горы, леса и остальное так же грамотно, как на
профессиональных картах, с учётом слоёв, ярусов и всего, что есть в программе. G1 (горы в областях) сделан
(DEC-102); осталось: дополнительные типы гор, G2 лес, G3 слои и ярусы, G4 генератор гексов, G5 генератор материка.

Слова владельца (12.11): «горы разных размеров с учётом их положения друг к другу… чтобы слои могли отличаться…
алгоритм грамотно, а не бездумно; всегда сверяй результат с примерами, пока не доведёшь до идеала»; «нужно больше
вариаций»; «найди больше референсов разных типажей».

## Порядок работы (каждый пакет закрывается полностью: тесты, лист «было/стало», документы, commit)

1. **G1-доп. — типы гор** из каталога, как новые формы раскладки 5 (без новой версии, если формат не меняется):
   одиночный массив (вершина 1,2–1,5×, 3–8 спутников, кольцо холмов), вулкан/цепь вулканов/кальдера, плато и
   столовые горы, холмистый край (без оси, ±25 %), береговой хребет, сбросовый с обрывом. Как выбирать тип — решить
   и показать (рисунок в списке или номер рисунка); новый пункт списка — визуальное, назвать владельцу до внедрения.
2. **G2 Лес**: пятно с лопастями и заливами, плотная середина, кроны гребнями, передний ряд целых деревьев, зубчатый
   край, опушка группами 1–4 (7–10 %), смешение пород (вперемешку/рощами), ориентиры; типы из каталога: старый массив,
   хвойный пояс, фартук у подножия, ленты вдоль рек, болото с протоками, джунгли. Только для новых областей.
3. **G3 Слои и ярусы**: общий порядок «ниже — ближе» между областями одного слоя; лес у подножия гор и не в их ядре;
   хвойные выше по рельефу и ярусам суши; просветы у рек, озёр, дорог, поселений (через правила области/экологию).
4. **G4 Гексы** и **G5 Материк**: кольцо холмов вокруг гор, блоки биомов, дождевая тень, болота в дельтах, поселения
   у воды/на переправах/в бухтах, дороги по долинам и перевалам; разобрать полукруг у поселения на шаге материка.

## Как сверять с образцами (обязательно, по словам владельца)

- После каждой правки — лист рендером программы на **его ассетах**: `area-beauty-sheet`
  (`MAP_AREA_LAYOUT=5`, `MAP_AREA_BEAUTY=1`, `MAP_AREA_VARIANTS=range|massif` — шесть зёрен на листе; расширить под
  лес/новые типы). Смотреть рядом с образцом, называть расхождения и править, пока не совпадёт; по 6 вариантов, чтобы
  видеть разнообразие. Итог — секция «было/стало» на странице референсов (обновить, открыть вкладкой).
- Новые образцы — только открытые источники: веб-поиск, страницы уроков (mapeffects.co и др.), RSS Pinterest
  (`/<user>/<board>.rss`), RSS DeviantArt, RSS Reddit. Внутренний API Pinterest (`/resource/`) запрещён проверкой
  действий — не обходить. Много картинок смотреть листами-контактами (скрипт собрать во временной папке).
- Объёмный сбор образцов можно отдать фоновым агентам; выводы проверять самому по картинкам.
