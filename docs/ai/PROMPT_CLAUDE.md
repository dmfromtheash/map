# Подготовка поручения для Claude Code

По прямому запросу владельца подготовлен полный
[промпт Stage 19 для Fable 5.1](STAGE_19_FABLE_PROMPT.md), включая интернет, репозитории
и самостоятельное создание необходимых ассетов. Его подготовка не означает, что этап уже начат.

Промпт с текущими Git, handoff и профилем модели печатает помощник:

```powershell
pwsh -File tools/ai/New-ClaudeTask.ps1 -Model Fable
pwsh -File tools/ai/New-ClaudeTask.ps1 -Model Opus -Stage 19
```

Без `-Stage` продолжается текущая задача. Новый этап выбирается только по просьбе владельца.
Помощник не запускает реализацию или платную сессию модели. Перед передачей промпта прочитай его
и учти последние уточнения и разрешения владельца. Руководство: [CLAUDE_WORKFLOW.md](CLAUDE_WORKFLOW.md).

Запасной шаблон, если помощник недоступен:

```text
Среда: Claude Code
Модель: [точный профиль из docs/ai/claude-models.json, сверенный с выбором в интерфейсе]
Рабочая папка: [точный абсолютный путь]

Цель
[Один наблюдаемый результат.]

Контекст
- Сначала прочитай CLAUDE.md, AGENTS.md, CODEX.md, docs/STATE_HANDOFF.md и относящиеся решения.
- Примени профиль и относящиеся project skills по docs/ai/CLAUDE_WORKFLOW.md.
- [Нужные исходные файлы, пример или спецификация.]

Границы
- Входит: [закрытый список.]
- Не входит: [явные исключения и внешние действия.]
- Сохрани пользовательские изменения и архитектурные инварианты.
- Используй только инструменты, реально доступные в текущей сессии Claude Code.

Готово, когда
- [Проверяемый результат 1.]
- [Проверяемый результат 2.]
- Выполнена минимальная проверка из AGENTS.md.
- Работающий интерфейс и художественный результат проверены отдельно от тестов, если изменялись.

Финал
- Коротко: что изменено, что проверено и что осталось.
- Не выполняй commit, push, PR, release или публикацию без прямого разрешения.
- Заверши разделом ИТОГИ: Сделано; Что дальше; Реализация проекта — оценка всей актуальной
  roadmap с основанием. Не подменяй общую готовность процентом текущей задачи или тестов.
```

Не вставлять сюда статический список инструментов: фактический набор зависит от текущей сессии.
Codex-specific команды и `.agents/skills` для Claude не использовать.
