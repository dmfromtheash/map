## 2026-11-11 · R20b п. 2 — замер мира 1024² и разбор «Суша и моря» 326 → 495 мс · Claude

**Разбор:** замер Sol сравнивал в одном прогоне голый генератор и обёртку R20 (`ControlledHexGeneration`): это не
замедление между версиями, а цена обёртки. Подтверждено новым профилем `hex-world-1024` (все 7 шагов подряд, ядро и
обёртка от одного входа, пары чередуются): «Суша и моря» 475 → 706 мс (+49 %) — настоящая, не шум.
**Причины:** (1) каждая из ~1 млн клеток заново копировалась с причиной и хэшировалась в общую таблицу; (2) старая клетка
искалась по координате для каждого гекса, неизменённые чанки тоже обходились; (3) у «Поселений» для каждого поселения
перебирались все реки и их гексы; (4) без защиты и выделения всё равно обходились гексы всех путей.
**Исправлено:** память «экземпляр + причина → клетка» (до 4096 записей), сравнение досок по чанкам с пропуском того же
чанка, множество гексов рек один раз на шаг, без обхода путей, когда всё разрешено.
**Замер (DM, 3 запуска × 3 пары, чередование старой и новой сборки, медианы 9):** полный мир 4056 → 3467 мс (−15 %);
обёртка по шагам: Суша 706 → 597, Холмы 282 → 237, Климат 534 → 453, Реки 735 → 696, Поселения 547 → 302,
Дороги 366 → 320, Государства 867 → 842 мс. Хэш результата (все клетки с причинами, пути без случайных id, регионы)
одинаковый у старой и новой — `7FC2C4964616A9B8`. Остаток обёртки у «Суши» (~+130 мс) — запись 1 млн изменённых клеток.
**Проверено:** Core Hex/Generation 90/90, Presentation 69/69, Persistence 91/91, `native-generation-control` 37/37.
