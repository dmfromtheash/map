# 00. С чего начать — карта документов

Map — личная нативная офлайн-программа владельца для его Windows x64 ПК.

## Вход в сессию (2 файла)

1. `docs/STATE.md` — где проект сейчас, что открыто, правила владельца.
2. `AGENTS.md` — правила (для Claude подключается через `CLAUDE.md` автоматически).

Дальше — чек-лист `docs/00_STAGE_PROTOCOL.md` и только документы по теме задачи.

## Три слоя памяти проекта

| Вопрос | Где | Когда читать |
|---|---|---|
| Где мы сейчас? | `docs/STATE.md` (до 60 строк) | всегда |
| Что было? | `docs/journal/<месяц>.md` | по правилам `docs/journal/README.md` |
| Почему так? | `docs/DECISIONS.md` (DEC-NNN) | когда задача касается темы решения |

## Правила и процесс

| Файл | Назначение |
|---|---|
| `AGENTS.md` | все правила для любого исполнителя |
| `CLAUDE.md`, `CODEX.md` | только особенности Claude Code и Codex |
| `00_STAGE_PROTOCOL.md` | чек-лист этапа (12 шагов) и формат отчёта |
| `00_STAGE_REFERENCE.md` | как проверять, стоп-условия, отвергнутые подходы, известные падения, разрешения, команды |
| `ai/PROMPT_CLAUDE.md`, `ai/PROMPT_CODEX.md` | шаблоны разовой задачи |
| `ai/CLAUDE_WORKFLOW.md` | выбор модели Claude и вспомогательные скрипты |
| `ai/MAP_ROADMAP_2026-10_PROMPT.md` | цикл работы по дорожной карте |
| `ai/MAP_R09_STYLES_PROMPT.md` | промпт следующей сессии (R09: приёмка света, стили, варианты, хендауты) |
