# 00. С чего начать

## Текущий режим

Map — личное офлайн-приложение для одного владельца на его текущем Windows x64 ПК.

Обычная работа использует production solution `Map.slnx`, одну Release-сборку и при необходимости
один адресный тест или короткий smoke в настоящем окне.

Полезный код предыдущих этапов сохраняется. Точный product `HEAD`, незакоммиченная работа,
статусы этапов и единственное следующее действие указаны в [STATE_HANDOFF](STATE_HANDOFF.md).
Отсрочка не является откатом к старому коду. Stages 21/22 отложены.
По решению владельца от 2026-09-09 (DEC-037) все нынешние ассеты, текстуры и исходные
художественные пакеты удалены для переделки. Библиотека пуста и автоматически не наполняется.
Кисть Земли и каталог сохранены как функции, доступно рисование цветом.
Текущая максимальная схема проекта v9 нужна только картам с раскраской Земли.

## Читать в таком порядке

1. `AGENTS.md`.
2. Для Codex — `CODEX.md`, для Claude Code — `CLAUDE.md`.
3. Актуальный верх `docs/STATE_HANDOFF.md`; нижние исторические срезы — по необходимости.
4. Относящийся к задаче раздел `docs/02_FUNCTIONAL_SPEC.md`.
5. Текущий пункт `docs/06_DEVELOPMENT_ROADMAP.md`.
6. Относящиеся записи `docs/DECISIONS.md`.
7. Для истории уже принятого Stage 12A — `docs/STAGE_12A_NAMED_CHECKPOINTS.md`.
8. Для истории реализованного Stage 12C — `docs/STAGE_12C_FULL_EXPORT.md`.
9. Для границы GitHub — `docs/GITHUB_PROJECTS.md`; сейчас любые remote-действия запрещены.
10. Для разовой передачи задачи — один из коротких шаблонов в `docs/ai/`.

Полный аудит с технической проверкой, графикой, производительностью и сравнением аналогов:
[готовый промпт](ai/MAP_FULL_AUDIT_PROMPT.md). Его наличие не запускает аудит и не расширяет
обычный цикл проверки. При аудите охват документации отмечается явно; при небольшой правке
не нужно заново загружать весь архив.
