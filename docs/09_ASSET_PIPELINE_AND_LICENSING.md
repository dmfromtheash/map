## Источники, допустимые после фиксации

- создано владельцем/командой;
- заказано с передачей нужных прав;
- public domain/CC0 с доказанной страницей источника;
- permissive/open license, разрешающая конкретное использование;
- купленный pack с условиями, разрешающими использование в локальной библиотеке;
- пользователь импортирует материал для своей локальной работы и сам подтверждает права.

## Запрещено по умолчанию

- извлекать ассеты Inkarnate или другого конструктора;
- перерисовывать чужой pack слишком близко;
- скачивать изображения из поиска без лицензии;
- класть в starter pack «временные» материалы неизвестного происхождения;
- использовать шрифт без права встраивания и применения в проекте;
- считать AI generation автоматически свободной от прав третьих лиц.

## Manifest pack

Каждый стандартный pack содержит:

- pack ID/version/name;
- author/owner/contact;
- license ID, полный текст или URL + локальная копия, если разрешено;
- список файлов, SHA-256, тип, размеры;
- attribution requirements;
- usage/derivative flags;
- source/provenance и дата получения;
- default scale, anchor, tags;
- compatibility/schema version.

Pack manifest также может объявлять собственные логические `sets`: stable set ID, display name,
ordered variant IDs, cover ID, collection/tags и default placement metadata. Каждый variant
ссылается на файл из того же manifest по SHA-256 и не ослабляет его provenance/license. Set с
вариантами разных лицензий получает наиболее строгие ограничения и явное предупреждение.

## Импорт пользователя

Диалог не делает юридических заявлений за пользователя. Он спрашивает источник/лицензионный статус и даёт варианты:

- «создано мной»;
- «имею право использовать»;
- «только личное использование»;
- «не уверен».

Статус сохраняется вместе с provenance и не блокирует законную локальную работу пользователя без дополнительных оснований.

## Техническая обработка

1. Проверить формат и лимиты.
2. Удалить опасные активные части/отклонить неподдерживаемый SVG.
3. Вычислить hash.
4. Создать thumbnail.
5. Записать provenance.
6. Калибровать default scale по reference grid.
7. Добавить tags/pack.
8. Для multi-import создать/обновить logical set, порядок variants и cover без дублирования
   content по SHA-256.
9. Проверить roundtrip, прозрачность, set membership и migration singleton records.

Оригинал не изменяется. Производные хранят ссылку на source hash.

### Текущий decode/cache envelope

- original читается одним bounded handle: максимум 64 MiB encoded;
- metadata принимается до pixel allocation: максимум 32 768 по оси, 32 MiPixels и 128 MiB
  расчётного RGBA;
- SHA-256 считается по тем же байтам, которые затем встраиваются или декодируются;
- brush tip дополнительно ограничен 1024×1024;
- Skia image cache ограничен одновременно числом элементов (64) и 256 MiB conservative resident
  weight: расчётные RGBA pixels плюс encoded payload, который может удерживать lazy native image;
- Library thumbnail — максимум 512×512, cache 96 элементов / 64 MiB;
- место в обоих cache освобождается до нативного decode, чтобы limit был также peak gate;
- optional fallback thumbnail дополнительно ограничена 8 MiB encoded, 2048 по оси и 4 MiPixels,
  полностью декодируется для проверки и при любой ошибке отбрасывается, не делая исправный
  original недоступным.

Эти числа являются принятым интерактивным envelope DEC-015, а не обещанием полного учёта
native/GPU overhead. Реальный peak исследуется только при наблюдаемой проблеме на ПК владельца.

Favorite/recent/current variant являются локальным пользовательским состоянием и не меняют
лицензию или content identity. Исключение variant из set не удаляет original; удаление content —
отдельное подтверждаемое действие вне foundation-среза.

## AI-инструменты для будущих ассетов

Qwen-Image-Layered, TRELLIS.2, Blender/ComfyUI и облачные генераторы могут быть **экспериментальной производственной линией**, но не зависимостью приложения. Перед использованием нужны отдельные проверки лицензии модели, данных/outputs, условий использования, качества, сходства с чужими наборами и ручная художественная доработка.

## Дизайн

Можно изучать общие UX-паттерны редакторов, сохраняя собственное оформление. Действующая система
Blue Atlas/Onest и правила интерфейса уже описаны в [DESIGN_SYSTEM.md](DESIGN_SYSTEM.md).
Очистка художественной библиотеки не удаляет тему, шрифты, иконки или заставку интерфейса.
Новое наполнение должно иметь собственное происхождение и согласованный графический язык.
