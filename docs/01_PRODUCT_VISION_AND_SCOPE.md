# 01. Видение продукта и границы

## Коротко

`Map` — нативная офлайн-программа для Windows, в которой человек без навыков профессионального иллюстратора собирает карты мира, регионов, городов, помещений, боевых сцен и изометрических сцен из слоёв, форм, линий, текста, текстур и собственных ассетов.

## Проблема

Существующие удобные конструкторы часто зависят от аккаунта, браузера, подписки, облачного каталога и интернета. Профессиональные графические редакторы мощны, но требуют слишком много ручной работы и знаний. Нужна локальная программа, которая сочетает:

- понятный предметный язык «земля, стены, дороги, подписи, сетка, ассеты»;
- неразрушающее редактирование слоями и масками;
- быстрый результат из готовых собственных пакетов;
- надёжное локальное хранение и экспорт;
- расширенные настройки, которые не мешают новичку.

## Пользователь

Единственный пользователь Map — владелец проекта на своём текущем Windows x64 ПК. Программа
делается под его карты, привычки и локальные ассеты; отдельная рыночная аудитория и матрица
совместимости не планируются.

## Главный пользовательский результат

Пользователь за одну сессию может:

1. выбрать тип и размер карты;
2. собрать землю/помещение;
3. покрасить поверхности;
4. расставить собственные ассеты;
5. добавить дороги, стены, зоны, подписи, заметки и сетку;
6. безопасно сохранить проект;
7. закрыть программу, открыть файл снова без потерь;
8. экспортировать готовое изображение без подключения к сети.

## Измеримые цели первой стабильной версии

Цифры — продуктовые ориентиры, а не результаты текущего аудита. Первоначальные бюджеты ниже
уточняются принятыми решениями и датированными измерениями в handoff. DEC-035/036 задают цель
40+ FPS для названных рабочих сценариев; старый ориентир 60 FPS не превращает каждую сцену в
новый обязательный gate. Число объектов, заполненность, окно и способ измерения всегда указывать.

| Метрика | Цель |
|---|---|
| Холодный запуск на рекомендуемом ПК | до 3 секунд до локальной библиотеки |
| Открытие типовой карты | до 5 секунд для проекта до 500 МБ |
| Навигация по сцене | 60 FPS целевое, не ниже 30 FPS при типовой сцене |
| Типовая сцена | 10 000 объектов без деградации базового pan/zoom/select |
| Большая сцена | минимум 50 000 объектов и canvas 65 536×65 536 units без full-canvas bitmap; pan/zoom/select не ниже 30 FPS |
| Deep zoom | текущий верхний предел 1600%; обычный нижний 0,5%, Fit может подстроиться под большую карту; детализация штампа растёт до 400% по DEC-035/036, затем увеличивается тот же рисунок |
| Локальный каталог | минимум 10 000 пользовательских ассетов без полного декодирования каталога в память |
| Отмена | минимум 200 последних пользовательских транзакций в пределах бюджета памяти |
| Автосохранение | не блокирует UI дольше 100 мс; запись атомарная |
| Восстановление | после принудительного закрытия теряется не более интервала autosave |
| Экспорт | PNG потоково без единой полной raster surface (DEC-023), планировщик до 1 048 576 px по стороне при достаточных ресурсах; JPEG/WebP одним файлом до 16 384 px; пакет тайлов сохраняется. Предел планировщика не равен проверенному размеру |
| Сеть | 0 обязательных запросов для всех основных сценариев |

## Типы документов

Тип карты задаёт начальные пресеты, но не закрывает инструменты искусственно:

- **Мир / регион:** земля, береговые эффекты, границы, маршруты, подписи.
- **Город / поселение:** кварталы, дороги, здания, вода, ландшафт.
- **Battlemap / интерьер:** точная сетка, стены, двери/проёмы, помещения, мебель.
- **Сцена / изометрия:** ассеты с псевдообъёмом, точный порядок, маски перекрытий.
- **Пустой документ:** пользователь сам задаёт размер, единицы и сетку.

## Входит в продукт

- локальная библиотека проектов с миниатюрами, поиском, сортировкой и недавними файлами;
- создание из локального пресета/шаблона и клонирование;
- полноценный редактор из `02_FUNCTIONAL_SPEC.md`;
- импорт и управление собственными ассетами;
- локальные наборы собственных ассетов;
- сохранение, backup, recovery, checkpoints и миграции формата;
- экспорт изображения и композиции;
- локальная справка, подсказки и список сочетаний клавиш;
- прямой локальный запуск без регистрации и сети.

## Не входит без нового решения владельца

- аккаунты и подписки;
- сервер, облачная база, cloud sync и совместное редактирование;
- Marketplace, Community Explore, лайки и комментарии;
- встроенная продажа ассетов;
- генеративный ИИ в обязательном контуре;
- VTT, симулятор боя, персонажи и правила RPG;
- копирование дизайна, ассетов, названий пакетов или исходного кода Inkarnate.

## Определение функционального паритета

«1 в 1 по функционалу» означает: для каждого ключевого наблюдаемого сценария редактора существует наш самостоятельный офлайн-сценарий с эквивалентным пользовательским результатом. Это **не** означает пиксельное сходство, идентичное расположение кнопок, совместимость с закрытым форматом Inkarnate или перенос их сетевых функций.

## Критические риски

| Риск | Как снимается |
|---|---|
| Производительность сложного холста | отдельный spike до полного UI; измерения 1K/10K/50K объектов |
| Память кисти и undo | тайловое хранение, объединение штрихов, лимит бюджета, профилирование |
| Потеря файла | атомарная запись, backup, recovery, fault-injection tests |
| Дрейф формата | schemaVersion, миграции копии, golden fixtures |
| Нарушение лицензий | provenance manifest и запрет неизвестных материалов |
| Интерфейс перегружает новичка | progressive disclosure, простая панель по умолчанию, расширенные секции |
| Opus сам расширяет архитектуру | ограниченные задания, список разрешённых файлов, приёмка тимлидом |

## Решения владельца

- DEC-001—DEC-008 приняты 25.08.2026;
- поддерживается только фактическая Windows x64 владельца;
- перед производственным дизайном предоставить собственные референсы и ассеты;
- определить, нужен ли в будущем коммерческий выпуск и какие лицензии пакетов допустимы.
