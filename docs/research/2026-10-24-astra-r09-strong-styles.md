## А. Приёмы и стоимость

NPR означает *нефотореалистичный рендеринг*: сюда входят и живописные стили.

**Как читать стоимость:** `S` — суммарные логические выборки текстур на выходной пиксель для предложенного небольшого ядра. На **2560×1440**: `1S ≈ 3,69 млн`, `10S ≈ 36,9 млн`, `100S ≈ 369 млн` выборок. Это **собственная арифметическая оценка**, без записи буферов, дополнительных масок и учёта кэша. Билинейная выборка считается одной операцией; миллисекунды так не предсказываются. `H` — поле вокруг тайла в пикселях рабочего разрешения.

**Важные ограничения реализации:**

- Квантование в **строго заданную палитру** требует выбора её цветов. Обычная интерполируемая LUT создаёт промежуточные оттенки.
- Из итогового RGB получится cel-подобная обработка яркости, но нельзя восстановить настоящее освещение по нормалям или отделить тёмную краску от тени.
- `SKColorFilter` подходит для преобразования цвета; соседние пиксели и координатные узоры требуют shader/image-filter пути. В SkSL дочернее изображение читается через `.eval()`. Промежуточные проходы следует материализовать: вложенный shader сам по себе не гарантирует кэширования дорогого результата. [Документация Skia](https://skia.org/docs/user/sksl/)

**Экспорт по тайлам:** все предложенные локальные варианты воспроизводимы при общем seed, координатах документа, фазе штрихов/точек и одинаковых параметрах. Поля рассчитываются по всей цепочке зависимостей; уменьшение изображения использует общую сетку. Gaussian нужно явно ограничивать конечным ядром. Итерационное растекание — фиксированным числом шагов. **Floyd–Steinberg нельзя независимо запускать на каждом тайле:** нужен перенос ошибки; для Map проще ordered/blue-noise dithering. Между разными GPU побитовое совпадение без проверки не обещается.

## Б. Десять рецептов для Map

**Общая защита гор:** до стилизации получить маску `I` вероятной туши — тёмных тонких деталей и значимых границ. Обрабатывать преимущественно заливки; в конце возвращать линию из исходного кадра. Обычный Sobel по всем цветам не заменяет такую маску: он может превратить фактуру в лишние линии. **Из одного RGB безошибочно извлечь исходную тушь невозможно**, поэтому сохранность рисунка требует сравнения на реальных горах.

Все числа ниже — начальные параметры для макетов при 1440p; размеры затем привязываются к масштабу документа.

1. **«Медная гравюра» — 5/5.**  
   Яркость → 4 тональных диапазона → штриховка под 25°/−35°, шаг 4–7 px → волнистые линии моря по маске воды → исходная тушь 90–100%. Цветные заливки становятся резным штрихом; узнаваемые линии гор остаются главными.

2. **«Цветная ксилография / укиё-э» — 5/5.**  
   Сглаживание заливок радиусом 2–3 → 6–8 собственных цветов с отдельными палитрами суши/воды → 2–3 ступени тона → лёгкий сдвиг цветного оттиска 0,5–1 px → неподвижная тёмная тушь. Большие плоские пятна резко меняют вид, контур сохраняет авторскую форму.

3. **«Двухкрасочная печать» — 5/5.**  
   Разложение на тёмно-синюю и терракотовую краски → halftone с периодом 5–8 px и разными углами → небольшая неравномерность покрытия → тушь сплошной краской. Точки заменяют полутона, но не дробят важные линии.

4. **«Акварель по мокрому» — 5/5.**  
   Упрощение заливок → 2–4 шага ограниченного растекания вне `I` → смещение пигмента 0,5–1,5 px → кайма 1–3 px → грануляция, зависящая от темноты пигмента и бумаги → исходная тушь. Это заметные потёки и скопления краски; тонкие линии не размываются вместе с ней.

5. **«Масло поверх рисунка» — 4/5.**  
   Тензор структуры → анизотропный Kuwahara радиуса 4–6 только на заливках → небольшое укрупнение цветовых масс → возврат туши 85–100%. Получатся вытянутые мазки; исключение линии из сглаживания удерживает характер гор. Настоящую толщину краски этот фильтр не моделирует.

6. **«Угольный лист» — 5/5.**  
   Монохромный тон → направленное зерно → растушёвка радиуса 2–4 в тенях → сухие пропуски по бумаге → исходная линия. Цвет исчезает, тени становятся бархатистыми. Светлые пропуски ослабляются на защищённых контурах.

7. **«Архивная карта XVII века» — 4/5.**  
   Сжатие заливок до 3–4 охристых тонов → коричневая тушь → береговая штриховка по расстоянию до берега → неоднородное выцветание → редкие foxing-пятна и волокна. Сильное отличие создаёт исчезновение современной цветности и новая графика воды; выцветание туши ограничить примерно 10%.

8. **«Лунный атлас» — 4/5.**  
   Раздельные палитры: почти чёрная вода, индиговая суша, серебристые света → 3–4 тональные ступени → высотная маска усиливает вершины → светлая береговая кайма → сохранение тёмной туши внутри светлых гор. Ночь строится на контрасте крупных областей; детали не должны проваливаться в общий чёрный.

9. **«Синька картографа» — 5/5.**  
   Однородная глубокая синяя основа → исходная тушь переводится в молочно-белую → второстепенные детали ослабляются → береговые изолинии по расстоянию → минимальная неоднородность носителя. Сохраняется геометрия авторского штриха, меняется его полярность. Не следует инвертировать весь RGB: тёмные заливки превратятся в белые кляксы.

10. **«Карманный пиксельный атлас» — 5/5.**  
    Уменьшение в 3–4 раза → 8–12 цветов → умеренный Bayer 4×4 в полутонах → увеличение nearest → контур, отдельно сведённый в ту же сетку. Опциональный двухцветный вариант даёт 1-bit. Мелкий штрих неизбежно теряется: это стиль для обзора карты, а не лучший режим сохранения каждой линии.
