# R09 · «Акварель»: пять школ (2026-10-25)

Исследование Claude (подагент, веб-поиск) для пяти вариантов «Акварели». Правило DEC-060: горы перерисовываются в технике,
цвета рисунка владельца — только маска. Генератор — `tests/Map.Rendering.Tests/StyleMockupDump.Watercolor.cs`
(`MAP_STYLE_WATERCOLOR=<папка>`, `MAP_LIGHT_ASSETS=<копии гор>`); страница — https://claude.ai/artifact/U4xy39kaqHzCM7pcAXZYuk
(первый проход, ждёт выбора). Hex — предложенные соответствия, не замеры. Не повторяют: суми-э (стиль «Тушь»), «перо и
размывка» (отвергнут), рукописную карту с берлинской лазурью (вариант «Старой карты»).

## Школы
- **Тёрнер, по сырому** (серия «Риги», 1842): края теряются, затёки, свет снят кистью или тряпкой; гора — одна мягкая
  сине-фиолетовая масса, чёткий край только по гребню. https://commons.wikimedia.org/wiki/File:J._M._W._Turner_-_The_Red_Rigi_-_Google_Art_Project.jpg
- **Английская плоская заливка** (Котман, Гертин): каждая плоскость — ровная заливка с жёстким краем, 2–4 лессировки
  ступенями, белое — оставленная бумага; гора — 3–4 грани мозаикой. https://commons.wikimedia.org/wiki/File:John_Sell_Cotman_002.jpg
- **Сухая кисть по торшону** (Хомер; Уайет не в общественном достоянии): краска на бугорках зерна, сильная грануляция;
  гора — подложка и сухие мазки по склону, гребень — голая бумага. https://www.metmuseum.org/art/collection/search/851681
- **Цинлюй** (Ван Симэн, «Тысяча ли рек и гор», 1113): минеральные краски на шёлке, кроющие; охра у подножия, малахит,
  азурит к вершинам; тушь в контурах. https://en.wikipedia.org/wiki/A_Thousand_Li_of_Rivers_and_Mountains
- **Современная фэнтези-акварель:** насыщенные переходы, соль (звёздочки), брызги, маскировочная жидкость (чистые белые),
  гранулирующие пигменты. Общедоступных образцов нет — современная практика.
- Запасные: ботаническая лессировка; тарасикоми (школа Римпа, краска в мокрое пятно — тёмные края, пятнистая середина).

## Исследования NPR
- Curtis et al., «Computer-Generated Watercolor», SIGGRAPH 1997 — три слоя (вода, пигмент, капилляры): затемнение края,
  затёки, грануляция, сухая кисть; Кубелка–Мунк для лессировок.
- Bousseau et al., NPAR 2006 / SIGGRAPH 2007 — модель плотности пигмента `C' = C·(1 − (1−C)(d−1))`, бумага, турбулентность,
  грануляция, затемнение края по градиенту.
- Luft & Deussen, NPAR 2006 — размытая и пороговая маска объекта = мягкая неровная заливка с тёмным краем.
- Montesdeoca et al., Expressive 2017, C&G 2017, MNPR 2018 — затемнение края разностью гауссиан, зазоры и наплывы,
  турбулентность, сухая кисть (высота бумаги против пигмента), грануляция, растекание.
- Wang et al., IEEE TVCG 20(10) 2014 — по-сырому в пространстве изображения, дрожание границ.
- Код: MNPR — MIT (проверено); Shadertoy — CC BY-NC-SA (только идеи). Макеты написаны заново.

## Как сделаны макеты (первый проход)
Общие входы как у гравюры второго круга: поле расстояний до берега, высота гор по силуэту (глубина под верхним краем +
расстояние внутрь), свет с северо-запада, крупные грани (размытие 8), главные линии (размытие 2), силуэт размытый 3 и 12.
1. **Тёрнер:** мягкая масса по размытому силуэту, тень гуще, затёки у подножия, снятые света, розовая лессировка гребней.
2. **Котман:** охра + плоские грани по свету (шалфей, сланец, сланец ×2), тонкая кромка высыхания, полосы моря.
3. **Сухая кисть:** мазки вдоль ската по зерну бумаги, сиена по главным линиям, голый гребень, искры у берега.
4. **Цинлюй:** полосы по высоте охра → малахит → азурит, шёлк, волны линиями туши, контур тушью.
5. **Соль и маскировка:** переход тёплое → фиолетовое по высоте, соль в тени и в море, снежные шапки бумагой, брызги.
Замечено для доводки: в 1-м вокруг гор видна рябь от кольца «затёк», в 3-м и 5-м пятна на суше крупноваты.
