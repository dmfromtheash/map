# Панель объекта и сетки: аудит функционального паритета

Дата: **26.08.2026**.

Статус: **FACT / PARTIAL / ACCEPTED SCOPE**.

## Граница исследования

Проверены приложенный владельцем снимок панели выделенного stamp, публичный официальный
`Stamp Tool Overview`, существующая спецификация Map и текущие Core / Persistence / Rendering /
Presentation / App. Закрытый редактор не автоматизировался, network/storage не инспектировались,
исходный интерфейс, графика и ассеты не копировались.

Требование «1 в 1» трактуется согласно DEC-003: одинаковый наблюдаемый результат и полнота
инструментов, но собственные названия, компоновка, tokens, icons и assets Map.

## Вывод

Движок уже содержит большую часть нужной семантики, но текущая панель скрывает её. Наличие поля в
документе или ветки renderer не считается готовой функцией: пользователь должен видеть текущее
значение, менять его точным и доступным control, отменять одной командой и получать тот же результат
после save/reopen и export.

## Выделенный stamp

| Возможность | Core / render / file | Текущий UI | Статус и требуемый срез |
|---|---|---|---|
| Заменить ассет без потери transform | Есть `ReplaceStampAssetCommand` и asset reference | Есть только во вкладке Assets и только после выбора каталожного ассета | `PARTIAL`: добавить явное действие из inspector с переходом к выбору ассета |
| Масштаб | Width/Height и transform command работают | Только отдельные W/H, нет пропорционального `%` и reset | `PARTIAL`: единый scale control, lock aspect и точные W/H; до реализации зафиксировать честную базу 100% |
| Поворот | Есть и сохраняется | Точное поле градусов есть | `FACT`, но значение должно находиться в общем блоке stamp без дублирования |
| Подслой `-10..10` | Есть, сортируется renderer и сохраняется | Control отсутствует | `BLOCKED UI` |
| Отражение по горизонтали / вертикали | Оба флага рендерятся и сохраняются | Доступно только горизонтальное | `PARTIAL` |
| Непрозрачность | `ObjectOpacity` рендерится и сохраняется | ViewModel принимает значение, control отсутствует | `BLOCKED UI` |
| Тень | Offset X/Y, blur и opacity рендерятся и сохраняются | Только включить/выключить с фиксированными значениями | `PARTIAL`: presets плюс раскрываемый custom |
| Blend mode | Renderer поддерживает 10 режимов | У объекта control отсутствует; есть только layer blend | `BLOCKED UI` |
| Blur | Рендерится и сохраняется | Control отсутствует | `BLOCKED UI` |
| Hue | Цветовая матрица работает, значение сохраняется | Только фиксированная кнопка `35°` | `PARTIAL` |
| Saturation | Работает как offset `-1..1` | Только фиксированное `+0.2` вместе с Hue | `PARTIAL` |
| Brightness / Contrast | Работают и сохраняются | Controls отсутствуют | `BLOCKED UI` |
| Reset отдельного параметра / всей внешности | Нейтральные значения определены моделью | Controls отсутствуют | `BLOCKED UI` |

Цветовые controls показывают понятные пользователю значения: Hue в градусах; Saturation,
Brightness и Contrast как проценты с нейтральной точкой `100%`. UI переводит их в существующие
offsets `-1..1`, не меняя renderer скрыто.

## Фигуры и другие вставленные объекты

- Для Shape требуются реальные controls fill color, stroke color/width, overall opacity, blend и
  blur. Сейчас значения существуют и рендерятся, но меняются только косвенными preset-командами.
- Line и Text используют тот же общий блок transform / sublayer / opacity / blend / blur, а ниже —
  свой типоспецифичный блок. Не создавать четыре расходящихся копии одной настройки.
- Любое изменение внешности проходит через одну `IEditCommand`; drag slider допускает live preview,
  но commit в history остаётся одной пользовательской транзакцией.

## Сетки

### Что уже есть

- `Square`, `HexFlat`, `HexPointy` в доменной модели;
- рендер обеих ориентаций hex;
- snap для объектов, nodes и portals при любом zoom;
- cell size, subdivisions, line width/color/opacity, offset X/Y, rotation, snap и export в модели и
  формате проекта;
- layer mask и порядок сетки среди других layers.

### Чего не хватает в панели

UI даёт только циклическое переключение трёх геометрий и флаг «в экспорт». Размер, subdivisions,
линия, цвет, opacity, offset, rotation и snap скрыты.

Принятые видимые presets:

1. квадратная;
2. диагональная ромбическая — существующая квадратная сетка с rotation `45°`, без нового file kind;
3. шестиугольная с плоским верхом;
4. шестиугольная с острым верхом.

После выбора preset все параметры остаются редактируемыми. «Ромбическая» здесь означает квадратную
ячейку, визуально повернутую на 45°; отдельную изометрическую проекцию нельзя выдавать за готовую без
отдельной геометрии и snap fixtures.

## Acceptance

1. Inspector показывает только применимые свойства и всегда показывает их фактические значения.
2. Все controls доступны с клавиатуры, имеют accessible name, единицы, checked/selected state и
   видимый focus.
3. Один slider gesture / numeric commit / preset — одна undoable command.
4. Undo/redo, save/reopen, preview и export сохраняют один и тот же результат.
5. Старые `.mapproj` открываются без изменения единственной копии; новые поля получают нейтральные
   defaults.
6. Автотесты покрывают bounds, mapping UI↔domain, persistence и render; UIA проходит stamp, shape и
   четыре grid presets в настоящем Release-окне.
7. В UI и репозитории нет заимствованных Inkarnate names, icons, assets или trade dress.
