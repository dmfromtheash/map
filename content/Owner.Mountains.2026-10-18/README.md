# Горы и текстуры владельца — 2026-10-18

`source/` — рисунки владельца без изменений (`1.png`–`6.png` — горы, `текстура 1/2.png` — земля), 1408×1408 RGBA,
из `Рабочий стол\Мои материалы\Творчество\Рисование\Референсы\Ассеты\Горы\Мои\без фона`.

Перерисовка 1 в 1 в высоком разрешении (`tools/`):
1. Real-ESRGAN ncnn-vulkan 0.2.5.0 (GPU), ×4 двумя моделями: `realesrgan-x4plus` (мягкие заливки) и
   `realesrgan-x4plus-anime` (чистые линии туши).
2. `refine.py <исходник> <anime> <x4plus> <выход> 0.6 1.25` — смесь 60/40, контур (альфа) берётся из исходника
   (Lanczos ×4, лёгкое повышение резкости края), зерно бумаги, которое нейросеть сгладила, восстанавливается
   шумом с той же местной силой, что в исходнике, но уже на полном разрешении (зерно остаётся чётким вблизи).
3. `finish.py mountain …` — обрезка по рисунку с полем 48 px, мастер ×4 (≈5400 px) в архив, в библиотеку —
   длинная сторона 4096 px, размеры кратны 16 (ресэмплинг в premultiplied, без тёмной каймы).
   `finish.py texture …` — центральный квадрат, 2048×2048, бесшовность в два прохода (по X, затем по Y),
   полосы смешивания с мягко изломанной границей.

Мастера ×4 и готовые файлы библиотеки: `artifacts/owner-mountains-2026-10-18/` (не в git, ≈200 МБ).
Встроена только `src/Map.Rendering/Textures/owner-snow-drifts.png` («Снег · наст со штриховкой», из «текстура 2»);
«текстура 1» (лёд) перерисована, но по решению владельца удалена из программы (копия в artifacts).
В библиотеку владельца горы ставятся как коллекция «Мои горы» (6 наборов): Ледяной пик (1), Двуглавая гора (2),
Гора с ледником (3), Горная гряда (4), Ледяные шпили (5), Ледяной клык (6).
